MI RANCHO INTELIGENTE — VERSIÓN 1

REQUISITOS: Android + Chrome. Para instalación PWA y GPS se requiere servir estos archivos mediante HTTPS (o localhost para pruebas). Abrir index.html directamente desde archivos no habilita correctamente las funciones PWA.

PUBLICACIÓN SENCILLA:
1. Extrae este ZIP.
2. Sube el contenido de la carpeta mi-rancho a un alojamiento estático HTTPS, como GitHub Pages o Netlify. No subas datos personales ni archivos de respaldo.
3. Abre la URL HTTPS desde Chrome en Android con conexión al menos una vez.
4. En menú de Chrome selecciona "Añadir a pantalla de inicio" o "Instalar aplicación" (según disponibilidad).
5. Abre la aplicación y prueba sin señal. La app guarda registros localmente mediante localStorage.
6. En Respaldo, exporta el archivo JSON y guárdalo en una ubicación segura.

ALCANCE:
- Registro individual de animales, movimientos financieros por actividad, tareas, lugares GPS y respaldo JSON.
- No incluye sensores, cámaras, rastreo remoto, fotos ni sincronización entre dispositivos.
- Los registros no están cifrados; usa bloqueo de pantalla. No se envían a servidores.
- No borres los datos del navegador antes de exportar respaldo.
- Esta es una versión piloto. Haz pruebas antes de confiarle información importante.
